  1. 1Go to github.com → click your profile picture (top right) → Settings
  2. 2Scroll to the bottom of the left sidebar and click Developer settings
  3. 3Click Personal access tokens → Fine-grained tokens
  4. 4Click Generate new token and give it a name like LINQ PR Dashboard
  5. 5Set an Expiration date
  6. 6Under Resource owner, select your group's repository (e.g. LINQ-ERP) — do not select your personal account
  7. 7Under Repository access, select All repositories
  8. 8Under Permissions, click + Add permissions and select Pull requests from the list — Metadata and Pull requests will appear in the permissions box, both defaulting to Read-only. Confirm both are set to Read-only before continuing
  9. 9Click Generate token
  10. 10Because the resource owner is an organization, your token will be pending admin approval — it won't work until an org admin approves it
  11. 11Once approved, copy the token — it starts with github_pat_ — and paste it in the field above
Your token is saved only in this browser and is never sent anywhere except GitHub's API.
