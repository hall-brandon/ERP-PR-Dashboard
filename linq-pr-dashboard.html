Connect to GitHub

Enter a GitHub personal access token with repo scope to load live PR data from the LINQ-ERP org.

Invalid token or no access to LINQ-ERP. Check your token has repo scope.
  1. 1Go to github.com → click your profile picture (top right) → Settings
  2. 2Scroll to the bottom of the left sidebar and click Developer settings
  3. 3Click Personal access tokens → Tokens (classic)
  4. 4Click Generate new token (classic) and give it a name like LINQ PR Dashboard
  5. 5Check the repo scope, set an expiration, and click Generate token
  6. 6Copy the token — it starts with ghp_ — and paste it in the field above
  7. 7If your org uses SSO, look for a Configure SSO button next to your new token and click Authorize next to LINQ-ERP
Your token is saved only in this browser and is never sent anywhere except GitHub's API.
